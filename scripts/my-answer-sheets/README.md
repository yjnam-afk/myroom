# 내 답안지 자르기 (2026-11-25)

「📝 내 정리」의 「내 답안지」(`src/data/myNotes.ts` 의 `ns19ans-*`) 그림을 원본 스캔에서 다시 만드는 도구다.
처음(2026-10-20) 자른 것은 조각마다 배율·좌우가 다르고 번호란이 잘려 있었고, 그때 쓴 도구는 남아 있지 않았다.

작업 폴더(scratchpad)에 이 파일들을 두고 차례로 돌린다. `pip install opencv-python-headless` 가 필요하다.

1. `python3 ingest.py <글자> <업로드 파일 머리 8자리> …` — 스캔 PDF 에 든 쪽 그림을 `pg/{글자}{묶음}-{쪽}.png` 로 푼다(같은 쪽이 두 번 든 것은 md5 로 건너뛴다).
2. `python3 run_rect.py` — 쪽마다 인쇄된 바깥 테두리 네 변을 찾아 반듯한 직사각형(너비 1000, 세로 1.557배)으로 편다 → `rc/`.
   테두리 점수가 낮은 쪽은 네 귀퉁이를 `quad_override.json` 에 손으로 적는다.
3. `python3 norm.py` — 괘선 23줄(22칸)을 찾아 줄 간격이 똑같아지게 세로로 다시 편다 → `nm/`. 사진으로 찍어 크게 휜 쪽은 `rc/` 를 그대로 쓴다.
4. `bundles.py` 에 묶음별 쪽 차례(쪽 번호 → 조각, 빠진 쪽은 None), `cut.py` 의 `SPEC` 에 답안마다 시작 쪽·줄을 적는다.
   `python3 strips.py <묶음> part 7` 이 줄 번호를 매긴 쪽 띠를 만들어 주니 「문N)」 줄을 눈으로 읽는다.
   빨간 점수가 문) 윗줄에 적혀 있으면 그 줄부터 자른다. 휜 쪽의 경계는 `YOVR` 에 픽셀로 적는다.
5. `python3 cut.py` — 다음 문 직전까지(쪽을 넘겨도) 줄 단위로 잘라 한 장으로 잇는다. 종이 그늘을 걷어 내고 뒤쪽 빈 줄은 던다 → `out/ns19ans-*.webp`(너비 1000).

결과는 답안 저장소 `NS19기/내답안지/` 에 두고 `pages` 는 `/ans2/NS19기/내답안지/…` 로 적는다.
