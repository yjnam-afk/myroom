# 답안 데이터 (`peerAnswers/*.json`)

한 줄에 답안 하나. 타입(`PeerAnswer`)과 찾기 함수는 `src/data/peerAnswers.ts`.
**손으로 고치지 않는다** — `npx tsx scripts/answers.ts …`로 고치면 검사를 통과해야 저장된다.

| 묶음 | 내용 |
|---|---|
| 01 | 첫 손글씨 답안(토픽별), 드라이브 「모범답안 › 08. 답안정리」 정리 답안 |
| 02 | 드라이브 정리 답안 계속, 2025년 하반기 정리 |
| 03 | KPC IMPACT 모의고사 모범답안, 심화반·단합반 주간 답안, 교시 묶음을 문항별로 쪼갠 것 |
| 04 | 정리 답안·ITPE 모의고사 답안 |
| 05 | 할루시네이션 등 직접 올려 준 답안, 정리 답안 |
| 06~08 | ITPE 기술사회 기출문제 해설집(116~140회 정보관리·컴시응) |
| 09 | NS 19기 04주차 해설집, 01~03주차 해설집·답안지, 박찬이 기술사 답안지 |
| 10 | 132회 해설집, NS 19기 05~07주차 해설집·답안지, C-RAN 정리 |
| 11 | KPC 합숙훈련 해설집(104~120회 대비) |

칸: `id`(peer-…) · `period` · `no` · `question` · `exam`(해설집이면 「해설집」을 넣는다) · `topicTitles`(교재 서브노트 제목) ·
`questionIds`(문제은행 id — 같은 문제일 때만) · `score`/`maxScore` · `feedback` · `memo`(스캔 메모, 화면엔 안 그림) · `pages`.
