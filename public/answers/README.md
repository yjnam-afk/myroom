# 답안 스캔 이미지

출처별 폴더. 화면 경로는 `/answers/<폴더>/<파일>` 이고 `src/data/peerAnswers.ts` 의 `pages[].src` 가 가리킨다.

| 폴더 | 내용 |
|---|---|
| `기출해설집/정보관리/{회}회`, `기출해설집/컴시응/{회}회` | ITPE 기술사회 기출문제 해설집 |
| `NS19기/{주}주차/해설집`, `NS19기/{주}주차/답안지` | NS 19기 주간 실전모의고사 해설집 · 제출 답안지(점수·첨삭) |
| `NS19기/정리노트/…` | NS 19기 손글씨 정리 노트 |
| `KPC모의고사/{회}회` | KPC 기술사 IMPACT 실전모의고사 모범답안 |
| `정리답안/…` | 드라이브 정리 답안(드라이브 폴더 경로 그대로) |
| `ITPE모의고사/…`, `심화반/…`, `실전심화반/{반}`, `NS반모의고사`, `단합반모의고사` | 학원 모의고사 답안 |
| `기출합격답안` | 기출 회차별 합격 답안 |
| `_연결안됨` | 어느 답안에도 걸리지 않은 옛 스캔 |
| `기타` | 출처가 위에 안 맞는 것 |

배포(Vercel)에서는 빠지고 GitHub 원본에서 바로 읽는다(`next.config.mjs` fallback rewrite).
